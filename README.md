# Lab08
Lab Summary

In this lab, we learned about morphological image processing using OpenCV. We applied four basic operations: Erosion, Dilation, Opening, and Closing to a binary image containing different shapes and noise. Erosion shrinks objects, while dilation expands them. Opening helps remove small noise, and closing fills small holes and gaps. We also compared square and circular structuring elements and observed how their shapes affect the results. These operations are useful for noise removal and shape analysis in image processing.
